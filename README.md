# BgadAI

An AI wardrobe stylist (web app / PWA):

- 📸 Photograph your clothes → background removed, auto-tagged, added to your digital closet
- 🧭 Style onboarding (quiz + swipe) so outfits match *your* taste
- ✨ AI outfits from what you own — weather- and occasion-aware, with an explanation for each
- 🧩 Build your own outfits
- 🖼️ Upload outfits you love → recreate them from your closet, and get similar items to buy for the missing pieces

See **[docs/RESEARCH_AND_PLAN.md](docs/RESEARCH_AND_PLAN.md)** for the competitive research,
feature roadmap, UX principles, AI pipeline design and recommended tech stack.
